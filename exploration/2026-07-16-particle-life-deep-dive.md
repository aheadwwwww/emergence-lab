# Particle Life Deep Dive — 2026-07-16

## 项目概述

**Particle Life** (hunar4321, 3343★) — 基于粒子间吸引/排斥力的涌现人工生命系统。
核心理念：N种粒子类型 × N×N 交互矩阵（力参数g）→ 复杂自组织生命状模式。
代码极简：核心算法<100行，不包含碰撞检测（这是关键设计决策）。

**GPU Life** (silvernio, 101★) — Particle Life的WebGPU移植，使用计算着色器+前缀和空间哈希实现大规模粒子模拟。

## 核心算法

### 力计算（JavaScript版本，~50行核心）
```javascript
rule = (atoms1, atoms2, g) => {
    for (let i = 0; i < atoms1.length; i++) {
        fx = 0; fy = 0;
        for (let j = 0; j < atoms2.length; j++) {
            a = atoms1[i]; b = atoms2[j];
            dx = a.x - b.x; dy = a.y - b.y;
            d = Math.sqrt(dx*dx + dy*dy);
            if (d > 0 && d < 80) {
                F = (g * 1) / d;   // F = g/d，力随距离衰减
                fx += F * dx; fy += F * dy;
            }
        }
        a.vx = (a.vx + fx) * 0.5;  // 速度阻尼 0.5
        a.vy = (a.vy + fy) * 0.5;
        a.x += a.vx; a.y += a.vy;
    }
};
```

### 交互矩阵
以3种颜色为例：
```
         green    red     yellow
green    -0.32   -0.17    0.34     ← green对yellow吸引，对同类排斥
red      -0.34   -0.10      -      ← red被green排斥，对同类轻微排斥
yellow   -0.20      -     0.15     ← yellow对green轻微排斥，同类吸引
```
不对称矩阵是关键：A对B的力 ≠ B对A的力 → 复杂生态位

### 关键设计决策

1. **无碰撞检测**：hunar4321故意不做碰撞检测，这让数千粒子实时模拟成为可能。粒子可以重叠——这是与传统粒子系统的根本区别。

2. **O(n²) 直接计算**：原始版本用嵌套循环计算所有粒子对，不做空间优化。这对小规模(<1000粒子)足够了，但瓶颈明显。

3. **速度阻尼0.5**：`v = (v + F) * 0.5` 充当隐式摩擦/惯性，防止爆炸性加速。

4. **固定交互半径**：d < 80 的硬截断，超出范围力为0——非连续，但有效。

### 互补关系

Particle Life 和 Lenia 在涌现光谱上占据不同位置：
- **Particle Life**: 离散 → 连续涌现（粒子→群体）
- **Lenia**: 连续 → 离散涌现（场→形态）

两者可互补：
1. **混合系统**：Lenia场作为Particle Life粒子的"环境场"
2. **参数转换**：Lenia核函数 → 等效粒子交互力
3. **多尺度**：粒子微观 + 场宏观

## GPU Life 的空间优化技术

silvernio的WebGPU实现提供了4种引擎：

### 1. NSquared（朴素）
直接O(n²)，每个粒子检查所有其他粒子。GPU上可并行，但浪费带宽。

### 2. Atomic Linked Lists（空间哈希+原子链表）
- 粒子按cell_id分桶
- 每个cell用原子操作构建链表
- 粒子只检查相邻cell的链表
- 问题：原子操作在GPU上有竞争

### 3. Counting Sort（计数排序）
- 粒子按cell_id计数→偏移→排序
- 读取快（连续内存），构建慢（串行前缀和）
- 构建~100ms瓶颈

### 4. Prefix Sum（并行前缀和）⭐
- 关键改进：串行前缀和 → 并行前缀和
- 构建时间：~100ms → ~0.3ms（333x提升）
- 使用B0nes164的GPU前缀和算法
- 使数万个cell的模拟可行

### 技术洞察
并行前缀和在GPU粒子系统中的应用可直接迁移到：
- **大规模Lenia**：空间哈希替代全网格卷积
- **混合系统**：粒子+场在同一GPU pipeline
- **Neural Lenia**：邻域搜索替代全连接

## 核心洞察

1. **Particle Life证明了"少即是多"**：放弃碰撞检测、只用50行JS，产生了比很多复杂CA更丰富的涌现行为。

2. **不对称交互是涌现的引擎**：A→B ≠ B→A 创造非平衡态，驱动力流和模式形成。这与Lenia中核函数形状的非对称性异曲同工。

3. **空间哈希+前缀和是GPU粒子模拟的银弹**：从O(n²)到O(n)，从100ms到0.3ms——这是工程突破，不只是理论优化。

4. **粒子和场是两个互补范式**：我们已有Lenia（场范式），加上Particle Life（粒子范式）可以覆盖更广的涌现光谱。
