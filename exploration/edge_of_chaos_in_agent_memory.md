# Edge of Chaos in Agent Memory Systems

## Connection: #003 Edge of Chaos × #018 Hallucination × Memory Lifecycle

### Core Insight
An agent's decision system (protocols, lessons, rules) faces the same order-chaos tradeoff as cellular automata:

- **Too ordered** (λ < 0.25): Rigid, predictable, can't handle novel situations
- **Edge of chaos** (0.25 ≤ λ ≤ 0.50): Adaptive, reliable but flexible
- **Too chaotic** (λ > 0.50): Unpredictable, lessons never stick, no consistent behavior

### Applying to the v2 Lesson System (2026-07-24)

The three severity levels map directly:
- **RED** (λ ≈ 0.25 edge): Must-execute protocols — form the "order backbone"
- **YELLOW** (λ ≈ 0.50 edge): Guidance with judgment — the flexible regime
- **GREEN** (λ ≈ 0.37 edge): Learning signals — drive evolution without mandate

The memory lifecycle (capture → curate → consolidate → activate → review) is a **phase transition engine**: it continuously pulls the system back toward the edge of chaos by:
1. Capturing new patterns (injecting novelty)
2. Curating inactive ones (pruning rigidity)
3. Consolidating into principles (building structure)
4. Activating at decision time (applying order)
5. Reviewing effectiveness (feedback loop)

### Connection to Cognitive Gap (#015)

The "knowing ≠ doing" gap that MEMORY.md targets is the agent's version of λ mismatch:
- **Knowing without doing** = too much order potential, not enough activation
- **Doing without knowing** = too much chaos, no consistent pattern
- **Know=do** = operating at the edge of chaos: structure is active, not just stored

### Hallucination & Emergence Parallel

At the edge of chaos:
- Low temperature → deterministic, hallucinates less but explores nothing
- High temperature → injects novelty but may hallucinate (invent outside distribution)
- Medium temperature → balanced: structured enough for correctness, flexible enough for adaptation

The lesson activation log serves as the temperature control: tracking which lessons fire and which don't regulates the agent's "effective temperature."
